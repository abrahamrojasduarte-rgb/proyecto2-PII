Bueno para ejecutarlo es muy simple, le da al boton de correr el programa
y escoge un personaje con el indice del 1 al 4, solo es eso ya que todos los personajes
ya estan creados

Qué hace el proyecto\
Te muestra un menú para elegir personaje (Knight, Wizard, Rogue o Priest)
Cada uno tiene una habilidad pasiva distinta\
Recorrés 3 niveles con varias salas cada uno
En cada sala aparecen enemigos aleatorios y a veces eventos random (trampas, tesoros, etc.)
Al final de cada nivel hay un jefe
Si ganás los 3 niveles, victoria. Si te quedás sin vida, game over.
Al terminar se genera un reporte en report.txt y un log en log.txt

En el proyecto se evidencia un uso de lo visto en clase como
Herencia y polimorfismo (Entity, Room, Ability)
Clases abstractas con métodos virtuales puros
Templates (Item)
Iterador personalizado (Inventory)
Sobrecarga de operadores (==, <, >, +=, -=, <<)
Manejo de archivos (lectura y escritura)
Excepciones (try/catch)
Patrón Strategy (habilidades)
STL (vector, string)
Memoria dinámica con destructores
